# Roadmap

The original scope and sequence are retained:

1. **Shared design system and temporary preview.** Refine the Connect 2-inspired layout while preserving native equipment-dependent behavior; verify rendering and input on CMU.
2. **Modular installer and rollback, first on a firmware copy.** Copy-level engine evidence exists. Resolve temporary service startup, collect real preflight, verify bounded persistent storage and reversible startup before live integration.
3. **First visual module on the vehicle, then other groups.** Verify the first complete module, native settings variants and hardware transitions before broad rollout.
4. **Custom application runtime and a new speedometer.** Not implemented; follows verified visual modules.
5. **Separate complex multimedia redesign.** Native radio, player and other complex applications require dedicated compatibility and resource work.

Completion requires evidence for every stage. Passing host tests or a RAM-copy installer test does not close the full project.
