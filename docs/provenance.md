# Authorship, provenance and distribution review

## What is js/run.js?

`run.js` is a generated output name, not an upstream product or a license identifier. Different cmu-next packages use different scripts at that path; they must not be merged.

| Package | Source of generated JavaScript | Included material |
| --- | --- | --- |
| Temporary retrofit 0.6.2–0.8 | Project-developed visual adapter in `history/retrofit/<version>/runtime.template.js`; reconstructed by `tools/build-retrofit.py` | Embedded PNG assets and, where used, Source Sans 3. The containing file has mixed provenance. |
| Manager | Project-developed UI in `src/manager/ui.js` plus `src/manager/ui.css`; generated by `tools/build-manager.py` | Manager interface and calls to the local service; this is separate from the visual adapter. |
| MP3 loader 1.0.0 | `tools/build-loaders.py` and zero-PCM audio described in `assets/audio/provenance.json` | An ID3 title invokes the existing CMU `utility.loadScript` API to load local `js/run.js`. It does not implement that firmware API. |

The current source tree identifies these JavaScript adapters as cmu-next development, not redistributed complete Mazda application sources. This is a description of the inspected build inputs, not an exhaustive originality or copyright clearance opinion. Calling existing firmware APIs does not transfer ownership of those APIs or establish authorship of the underlying entry technique.

## Rights boundaries

PolyForm Noncommercial 1.0.0 applies only to project-authored material to the extent the contributors hold licensable rights. It does not override upstream licenses or grant rights to Mazda/Johnson Controls assets, trademarks, copied designs, or third-party fonts. An asset redrawn from a reference is not automatically cleared for redistribution.

Source Sans 3 keeps its SIL OFL notice. Optional encoders and compiler/runtime dependencies keep their upstream terms; a build-tool license and an output file license are separate questions. Any distributed linked executable needs its own dependency review.

Some included graphics are OEM-derived or have incomplete individual provenance. Their redistribution permission has NOT been established by this document. A generic attribution or an “all rights remain with their owners” statement does not supply permission. Before describing a combined theme package as cleared for redistribution, inventory every asset (source URL/file, author, license/version, changes, hash, permission evidence), then replace, omit or obtain permission for unresolved material. This remains open work.

## Historical publication

The first public snapshot and earlier Git commits retain a legacy MP3 carrier with unconfirmed redistribution terms. Current replacement files do not erase those historical copies, forks or downloads. Removing release attachments or rewriting Git history would be separate actions, not proof that all copies disappeared.

This checklist reduces avoidable mistakes. It is not a legal clearance or a guarantee against claims; jurisdiction-specific distribution and anti-circumvention questions require qualified advice for the intended countries and release contents.
