# Third-party material

- **Source Sans 3:** Adobe, unmodified regular TTF, SIL OFL 1.1. The included license accompanies the font and all historical embedded copies. It is an alternative font, not a verified original Connect 2 font.
- **Mazda / Johnson Controls:** the project interoperates with existing Connect 1 APIs. It does not include a complete firmware image, extracted root filesystem, the original or modified OEM index.html, navigation data, vehicle backups, or downloaded manual screenshots. The owner confirms that the theme graphics were drawn by them, with Connect 2 screenshots used only as visual references; no OEM graphic files were copied or extracted. Existing firmware APIs and trademarks are not project-owned.
- **musl / Zig:** C sources may be compiled with Zig 0.15.2 and musl for the inspected ARM/Linux target. Toolchains and prebuilt runtime libraries are not vendored in this repository. Upstream musl and Zig notice texts are preserved under `notices`. If distributing linked executables, include the appropriate upstream notices.
- **Loader carrier:** current loader 1.0.0 audio is synthesized locally from zero PCM samples, not copied from a third-party silence recording. The previous public snapshot used a legacy carrier with third-party metadata; its redistribution terms were not established, and it is superseded by the new loader packages. `lameenc` 1.9.0 (LGPL-3.0-or-later) is an optional build-only encoder; neither it nor a linked encoder library is bundled in the USB payloads. See `src/loaders/readme.md` and `assets/audio/provenance.json`.
- **Reference material:** Mazda Connect 2 official owner's manual and user-provided visual references informed the retrofit. Reference screenshots themselves are excluded from the source import.

The owner selected PolyForm Noncommercial 1.0.0 for project-authored code and documentation. Commercial use requires separate permission. The license text is preserved unchanged from the official PolyForm 1.0.0 source; the required copyright notice is in `notice.md`. This does not relicense the font, trademarks, or other third-party material. Review the respective asset terms before distributing a combined binary package.

## Generated scripts and owner-authored graphics

`js/run.js` is generated from project-developed JavaScript and can embed owner-authored graphics together with the separately licensed Source Sans 3 font. The owner’s graphic-authorship clarification supersedes earlier descriptions of the theme PNGs as OEM-derived or of unresolved origin. See [authorship and distribution review](provenance.md).
