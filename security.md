# Security and reporting

Do not post connection tokens, private vehicle reports, backups or complete firmware in public issues. Report reproducible findings with firmware version, component version, sanitized steps and the scope of any device observations.

The temporary service binds to loopback and accepts a restricted operation set against a marked RAM copy. It is an experimental engineering component, not a hardened permanent vehicle service. No production security support commitment is made.

The MP3 loaders intentionally use ID3/HTML rendering to load local code on owner-authorized CMUs. Use only with the device owner’s authorization. For rights, vulnerability or abuse concerns, open a sanitized issue at https://github.com/mrerikk/cmu-next/issues. Do not include tokens, private vehicle data or working attack material targeting third-party devices.
