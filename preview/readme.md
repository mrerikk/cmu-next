# Interactive interface preview

Download or clone the complete repository, then open `preview/demo.html` in a browser. Keep the directory structure: the preview loads the existing graphics and Source Sans 3 font from `history/retrofit/assets` using relative paths. There are no external network dependencies.

Use the on-screen Home, Back, Up, Down and Select controls, or arrow keys and Enter. The home menu, settings, phone, player and radio screens use simulated data. This is the preserved interactive 0.7 design study, not an emulator or a claim that every shown screen is implemented on CMU. No vehicle telemetry, installation commands or CMU service connections are used.

The README images are screenshots rendered from this HTML preview, not photographs or screenshots extracted from Mazda firmware. Graphics are owner-authored; Source Sans 3 retains its included SIL OFL license. Project-authored code and graphics use the project license.

Vehicle testing of cmu-next is limited to a Mazda Roadster ND, model year 2016, Japanese market. Other Connect 1 vehicles have not been tested.
